# Felicity Event Management System — Deployment

## Evaluation Links

Frontend:    https://dass-a1-jldm.onrender.com
Backend API: https://felicity-backend-55fy.onrender.com/api
Health Check: https://felicity-backend-55fy.onrender.com/api/health
Database:    MongoDB Atlas (cloud)

---

## Hosting

Both the frontend (static site) and backend (web service) are deployed on Render.
No Vercel, Netlify, Heroku, or Railway is used.

  Backend  — Render Web Service  — https://felicity-backend-55fy.onrender.com
  Frontend — Render Static Site  — https://dass-a1-jldm.onrender.com
  Database — MongoDB Atlas        — cloud-hosted, no local DB needed

Note: Both services are on Render free tier. Cold-start after inactivity takes
30-60 seconds on the first request.

---

## Backend — Render Web Service

Repository root: dass_a1/
Build command:   npm install
Start command:   node backend/server.js

Environment variables to set in the Render dashboard:

  NODE_ENV          = production
  PORT              = 5001
  MONGODB_URI       = <MongoDB Atlas connection string>
  JWT_SECRET        = <long random secret>
  FRONTEND_URL      = https://dass-a1-jldm.onrender.com

  EMAIL_HOST        = smtp.gmail.com
  EMAIL_PORT        = 587
  EMAIL_USER        = <gmail address>
  EMAIL_PASS        = <gmail app password>
  EMAIL_FROM        = Felicity Events <gmail address>

  DISCORD_WEBHOOK_URL = <optional — per-organizer webhooks set via profile>

  ADMIN_EMAIL       = admin@felicity.com
  ADMIN_PASSWORD    = <admin password>

The render.yaml at the repository root pre-configures all of the above.
Sensitive values (marked sync: false) must be entered manually in the dashboard.

---

## Frontend — Render Static Site

Repository root: dass_a1/frontend/
Build command:   npm install && npm run build
Publish dir:     build

Environment variable to set in the Render dashboard:

  REACT_APP_API_URL = https://felicity-backend-55fy.onrender.com/api

The frontend reads this at build time via Create React App's REACT_APP_* injection.
The value is also stored in frontend/.env.production for local production builds.

---

## Database — MongoDB Atlas

1. Create a free M0 cluster at https://cloud.mongodb.com
2. Add a database user with a password
3. Under Network Access, allow 0.0.0.0/0 (required for Render's dynamic IPs)
4. Click Connect -> Drivers and copy the connection string:
   mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/felicity?retryWrites=true&w=majority
5. Set this as MONGODB_URI in the Render backend environment variables

---

## Redeployment Steps

1. Push changes to the main branch on GitHub
2. Render auto-deploys both services on every push (auto-deploy is enabled)
3. Watch the deploy log in the Render dashboard for errors
4. After backend deploys, hit the health check URL to confirm it is live:
   https://felicity-backend-55fy.onrender.com/api/health

---

## CORS

The backend whitelists FRONTEND_URL. If the frontend URL changes, update
the FRONTEND_URL environment variable in the Render backend service dashboard
and redeploy.

---

## Default Credentials (post-deploy)

Admin email:    admin@felicity.com
Admin password: (value of ADMIN_PASSWORD env var set during deploy)

The admin account is auto-created on first server start if it does not exist.
Organizer accounts are created by the admin from the Admin Dashboard.
