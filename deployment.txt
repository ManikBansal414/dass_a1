## Deployment Steps

### 1. Database Setup
```bash
1. Create MongoDB Atlas account
2. Create a new cluster (Free tier M0)
3. Add database user with password
4. Whitelist IP addresses (0.0.0.0/0 for all)
5. Get connection string
```

### 2. Backend Deployment (Render Example)
```bash
1. Push code to GitHub
2. Connect Render to your GitHub repository
3. Create new Web Service
4. Select backend folder as root directory
5. Build command: npm install
6. Start command: npm start
7. Add environment variables from above
8. Deploy
```

### 3. Frontend Deployment (Vercel Example)
```bash
1. Push code to GitHub
2. Import project to Vercel
3. Select client folder as root directory
4. Framework preset: Create React App
5. Add environment variables
6. Deploy
```

### Quick deploy checklist (copyable commands)

Frontend (Vercel - steps to run locally before deploy):
```bash
# from repository root
cd client
npm install
npm run build
# Verify build output exists in client/build
ls build
```

Backend (Render - steps to run locally before deploy):
```bash
# from repository root
cd backend
npm install
npm start
# Confirm server runs on configured PORT (default 5000)
```

MongoDB Atlas (create connection string):
1. Sign in to https://www.mongodb.com/cloud/atlas
2. Create a new free cluster
3. Create a database user (username/password)
4. Network Access: Allow access from your deployment IPs or 0.0.0.0/0 (for testing)
5. Click "Connect" → "Connect your application" and copy the connection string
   Example: mongodb+srv://<username>:<password>@cluster0.abcd.mongodb.net/felicity?retryWrites=true&w=majority
6. Set this value as `MONGODB_URI` in your backend environment variables

## CORS Configuration

Update backend/server.js:
```javascript
const corsOptions = {
  origin: [
    'http://localhost:3000',
    'https://your-frontend-domain.vercel.app'
  ],
  credentials: true
};

app.use(cors(corsOptions));
```

## Security Checklist
✓ Environment variables properly set
✓ JWT secret is secure and unique
✓ MongoDB connection uses authentication
✓ CORS configured for specific domains
✓ Password hashing enabled (bcrypt)
✓ HTTPS enforced
✓ Rate limiting (recommended: express-rate-limit)
✓ Input validation (express-validator in use)
